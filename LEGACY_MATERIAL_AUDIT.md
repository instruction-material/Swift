# Legacy Swift Material Scope

## Current source

The maintained repository is `instruction-material/Swift`. It contains the
SAD1–SAD7 project packs, optional Shapes Studio, numbered supplemental scaffolds,
and the individual `Mod…` SwiftUI demonstrations.

The visible course follows SW1–SW20. Development and distribution lessons are
SW16–SW20, after the language, app-feature and device-validation work. Source
folder numbers retain earlier aliases and do not set the current lesson order.

## Archive boundary

Earlier archive notes refer to `AD1`–`AD6` and `SWIFT-COMB.pdf`. These PDFs are
not included in this repository. The `legacy/` directory currently contains a
scope note, not the archived PDF files.

Retain the distinction between historical references and the active project
packs. Archived portal, recording, profile-sharing or instructor-administration
instructions do not define the app project requirements.

## Reference roles

Shapes Studio remains optional enrichment. The `Mod…` folders preserve individual
demos and are not a second required course sequence. The SAD1–SAD7 packs supply
the staged starter/reference projects used by the visible course.

The numbered `SAD-##-…` supplemental folders contain generic screen/state examples.
They do not yet supply worked implementations of their topic-specific transfer
or extension assignments. A catalog link or the inventory script passing does
not establish that those assignments are complete.
